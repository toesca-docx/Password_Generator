# 🔐 Password Generator

This is a simple Python password generator that allows users to create strong and customizable passwords based on user-defined criteria such as length, character types (uppercase, lowercase, digits, and special characters).

## 🛠 Features

- Choose the desired password length
- Option to include:
  - Uppercase letters
  - Lowercase letters
  - Numbers (digits)
  - Special characters
- Validates all user inputs
- Ensures at least one character type is selected
- Simple command-line interface

## 🚀 How to Use

1. Run the script:
   ```bash
   python your_script_name.py
   ```

2. Follow the prompts:
   ```
   Welcome to the Password Generator!
   Would you like to create a new password?

   1-Yes | 2-No:
   > 1

   Let's generate a new password!
   Enter the desired password length (positive integer):
   > 12

   Include uppercase letters?
   1-Yes | 2-No:
   > 1

   Include lowercase letters?
   1-Yes | 2-No:
   > 1

   Include digits?
   1-Yes | 2-No:
   > 1

   Include special characters?
   1-Yes | 2-No:
   > 1

   Your generated password is:
   @G5kz!P2qW#r
   Enter a name for this password:
   > MyBankPassword
   ```
